# محصول فاخر — نظام أريب

نسخة نظام أريب كما هي، مع استبدال بيانات الهوية فقط لصالح **محصول فاخر**:

- اللوجو الرسمي لمحصول فاخر.
- ٦٤ صنفًا و١٠ أقسام بالأسعار والأوصاف الخاصة بمحصول فاخر.
- صورة مستقلة لكل صنف.
- روابط إنستجرام والموقع الخاصة بمحصول فاخر.
- نفس واجهة أريب ونفس لوحة الإدارة ونفس السلوك بدون إعادة تصميم.

## الروابط

- المنيو: https://a7madshiref001-ctrl.github.io/luxury-crop-system/
- لوحة الإدارة: https://a7madshiref001-ctrl.github.io/luxury-crop-system/owner.html

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | منيو العميل الأصلي لنظام أريب |
| `owner.html` | لوحة إدارة أريب الأصلية |
| `data/menu.js` | أصناف وأسعار وروابط محصول فاخر |
| `data/sales.js` | إعدادات الطلبات والعروض والكومبو |
| `assets/img/items/` | صور الأصناف |
| `assets/menu.js` و`assets/owner.js` و`assets/sys.js` | محرك أريب الأصلي |

النظام يعمل بالتخزين المحلي في المتصفح مثل أريب: بيانات لوحة الإدارة مرتبطة بنفس المتصفح، وإرسال الطلب يفتح واتساب. رقم واتساب استقبال الطلبات ما زال الرقم التجريبي الموجود في قالب أريب لأن مصدر محصول فاخر لا يحتوي رقم استقبال موثقًا؛ غيّره داخل `data/sales.js` قبل استخدام الطلبات فعليًا.
