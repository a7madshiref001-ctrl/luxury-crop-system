# محصول فاخر — المنيو الرقمي

واجهة منيو رقمية مخصصة لصالح **محصول فاخر**:

- اللوجو الرسمي لمحصول فاخر.
- ٦٤ صنفًا و١٠ أقسام بالأسعار والأوصاف الخاصة بمحصول فاخر.
- ٦٤ صورة أصلية مجمعة في ١١ ملف WebP مضغوطًا؛ كل ملف يضم حتى ٦ منتجات لتسريع التحميل.
- واجهة افتتاحية مخصصة، وقسم عروض باسم **Luxury Crop offers**.
- الطلب متاح من الطاولة فقط.
- لوحة إدارة محلية لمعاينة المبيعات والأصناف والتحكم.

## الروابط

- المنيو: https://a7madshiref001-ctrl.github.io/luxury-crop-system/
- لوحة الإدارة: https://a7madshiref001-ctrl.github.io/luxury-crop-system/owner.html

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | منيو العميل الأصلي لنظام أريب |
| `owner.html` | لوحة إدارة أريب الأصلية |
| `data/menu.js` | أصناف وأسعار وروابط محصول فاخر |
| `data/sales.js` | إعدادات الطلبات والعروض والكومبو |
| `assets/img/atlases/` | صور الأصناف المجمعة والمضغوطة |
| `assets/menu.js` و`assets/owner.js` و`assets/sys.js` | محرك أريب الأصلي |

## قيود التشغيل الحالية

- بيانات لوحة الإدارة والطلبات محفوظة محليًا في المتصفح وليست مشتركة بين أجهزة العملاء والإدارة. التشغيل الحقيقي متعدد الأجهزة يحتاج خادمًا وقاعدة بيانات وتسجيل دخول آمنًا.
- رقم واتساب استقبال الطلبات ما زال تجريبيًا لأن الملفات لا تحتوي رقمًا موثقًا. زر الإرسال معطّل بأمان إلى أن يتم وضع الرقم الحقيقي داخل `data/sales.js`.
