# محصول فاخر — المنيو ونظام الطلبات

منيو عميل ولوحة إدارة لمحصول فاخر. يحتفظ التصميم الحالي كما هو، ويضيف مسار طلب مباشر بدل واتساب.

## ما يعمل بعد الربط

- العميل يختار الطاولة ويرسل الطلب من المنيو.
- السعر يُحسب داخل قاعدة البيانات، لذلك لا يمكن اعتماد سعر معدّل من المتصفح.
- الطلب يظهر لحظيًا في لوحة الإدارة مع رقم مستقل.
- حالات الطلب: جديد، قيد التحضير، جاهز، مكتمل، ملغي.
- تعديل أسماء المنتجات وأوصافها وأسعارها وتوفرها.
- تعديل العروض وأسعارها وصورها ومكوناتها.
- فتح وإغلاق استقبال الطلبات وتحديد عدد الطاولات.
- دخول الإدارة بالبريد وكلمة المرور، مع صلاحيات RLS داخل قاعدة البيانات.

## تفعيل قاعدة البيانات مرة واحدة

1. أنشئ مشروع Supabase.
2. شغّل `supabase/migrations/20260921030000_secure_ordering.sql` في SQL Editor.
3. شغّل `supabase/seed.sql` لإضافة المنتجات والعروض والإضافات الحالية.
4. أنشئ مستخدم الإدارة من Authentication > Users.
5. نفّذ الأمر التالي في SQL Editor بعد استبدال البريد:

```sql
insert into public.admin_users (user_id, display_name)
select id, 'مدير محصول فاخر' from auth.users where email = 'ADMIN_EMAIL_HERE';
```

6. ضع Project URL وPublishable/anon key فقط داخل `data/backend-config.js`.

لا تضع `service_role` أو كلمة مرور الإدارة في أي ملف بالموقع.

## الاختبار

```powershell
node scripts/generate-supabase-seed.mjs
node scripts/qa.mjs
node scripts/backend-contract-test.mjs
```

المنيو النهائي: https://luxury-crop-system.pages.dev/

لوحة الإدارة: https://luxury-crop-system.pages.dev/owner

كل روابط النسخ وأكواد QR تُبنى من `SITE_CONFIG.menuUrl` فقط. أي استضافة قديمة تعيد التوجيه إلى الرابط النهائي، والـQR يُنشأ محليًا داخل لوحة الإدارة من دون خدمة خارجية.

دخول الإدارة محمي بصلاحيات RLS، وحدود Supabase Auth حسب عنوان IP، وقفل إضافي في الواجهة بعد 5 محاولات فاشلة خلال 15 دقيقة. كلمات المرور الجديدة تتطلب 12 حرفًا على الأقل مع حروف كبيرة وصغيرة ورقم ورمز.
